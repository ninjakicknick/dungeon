# DUNGEON

A deliberately small first-person dungeon crawler inspired by tabletop solo dungeon games and late-'80s/early-'90s grid crawlers.

Native resolution: **160×120**.

The dungeon is a 2D grid presented through composited perspective artwork. It is not a 3D game.

The goal is immediate play with extremely low cognitive overhead.

## Project rule

**Build the game we want to play. Do not build a general-purpose engine.**

Abstractions are introduced only when the playable game requires them.

**Automate the friction. Don't generalize the solution.**
